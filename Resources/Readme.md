# 🍔 OmniFood Responsive Landing Page

## 📌 Project Overview

This project is a responsive landing page for a food delivery website called **OmniFood**. It is built using **HTML5** and **CSS3**. The website includes a modern user interface with multiple sections such as Hero, How It Works, Cities, Testimonials, Pricing Plans, and Footer.

The layout is fully responsive and works well on desktop, tablet, and mobile devices.

---

## 🚀 Features

- Responsive Navigation Bar
- Hero Section with Background Image and Overlay
- Call-to-Action Buttons
- How It Works Section
- Cities Grid Layout
- Customer Testimonials
- Pricing Plans
- Responsive Footer
- Mobile-Friendly Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Font Awesome (for icons)

---

## 📱 Responsive Breakpoints

| Device | Screen Width |
|---------|--------------|
| Desktop | 1200px and above |
| Tablet | Up to 834px |
| Mobile | Up to 390px |
